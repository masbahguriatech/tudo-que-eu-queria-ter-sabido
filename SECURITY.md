# 🔒 Segurança

Valeu por querer deixar esse fliperama mais seguro! 💜

## Como reportar uma falha

Por favor, **não abre issue pública** pra falha de segurança. Usa o reporte privado do GitHub:

1. Vai na aba **Security** deste repositório
2. Clica em **Report a vulnerability**
3. Conta o que tu encontrou, como reproduzir e qual o impacto

Eu respondo assim que der e te aviso quando a correção estiver no ar.

## O que conta como falha

- Qualquer jeito de executar código ou injetar HTML no site
- Links ou conteúdos que levem pra fora do que foi validado no build
- Problemas no save local (por exemplo, um save adulterado que quebra ou explora o site)
- Problemas no fluxo de publicação (GitHub Actions)

## O que não conta

- Editar o próprio save pra ganhar XP. O save é teu, o XP é teu, não tem ranking online. Pode trapacear à vontade 😄

Os detalhes de como o projeto se protege estão no [Manual do fliperama](./docs/PROJETO.md#-segurança).
